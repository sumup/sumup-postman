# SumUp API Postman Collection

**This repository is deprecated.** The Postman collection now lives in [sumup/sumup-openapi](https://github.com/sumup/sumup-openapi#api-collections).

- [Download the Postman collection](https://github.com/sumup/sumup-openapi/blob/main/SumUpAPICollection.json).
- [Fork the collection in SumUp's public Postman workspace](https://www.postman.com/sumupengineering/workspace/sumup-developers).

The JSON files in this repository remain available for existing download links, but are no longer updated. Use `sumup-openapi` for current collections, import instructions, and generation tools.

For API documentation, see the [SumUp developer portal](https://developer.sumup.com/api).
